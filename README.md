# 📊 E-Commerce Sales Analytics

## 📌 Project Overview
An E-Commerce Sales Analytics project using **SQL (MySQL)** for data cleaning and **Microsoft Excel** for data analysis and interactive dashboard development.

## 🛠️ Tools & Technologies
- SQL (MySQL)
- Microsoft Excel
- PivotTables & PivotCharts
- Excel Data Model
- Slicers & Timelines

## 📂 Dashboard Pages

### 1. Sales Overview
- Total Revenue
- Total Orders
- Total Customers
- Monthly Revenue
- Revenue by City

### 2. Customer Analytics
- Customer Segmentation
- Repeat Customers
- Top Customers by Revenue
- Customer Revenue Distribution

### 3. Product Analytics
- Top 10 Products
- Revenue by Product Type
- Product Performance
- Units Sold

### 4. Sales Trends & Growth
- Monthly Revenue Trends
- Revenue Growth %
- Month-over-Month (MoM) Growth
- Highest & Lowest Revenue Months

## 🗄️ SQL – Data Cleaning
- Duplicate record checks
- Missing value checks
- Data consistency validation
- Data preparation for analysis

## 📈 Key Skills
- Data Cleaning
- Data Analysis
- Customer Segmentation
- Business Intelligence
- Data Visualization
- Dashboard Development

## 🎯 Project Objective
To transform raw e-commerce sales data into meaningful business insights and support data-driven decision-making.
